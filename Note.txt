llama.cpp -> Vulkan
-------------------
1: Run it whenever you need the local model

$ ./build/bin/llama-server \
  -hf Qwen/Qwen2.5-3B-Instruct-GGUF:Q4_K_M \
  --alias local-incident-model \
  --device Vulkan0 \
  --n-gpu-layers 99 \
  --ctx-size 4096 \
  --parallel 1 \
  --jinja \
  --host 127.0.0.1 \
  --port 8082

2: Before start check:
curl -fsS http://127.0.0.1:8082/health

3: Where to find llama.cpp models

    https://huggingface.co/docs/hub/gguf

    Hugging Face is the main place to find models for llama.cpp. Start with its GGUF model catalogue (https://huggingface.co/models?library=gguf&sort=trending).

    When choosing a model:

    1. Select Text Generation for your notebook’s chat and incident-analysis tasks.
    2. Look for Instruct or Chat in the name.
    3. Check the model page for llama.cpp usage instructions.
    4. Open Files and look for .gguf files and a quantization such as Q4_K_M.
